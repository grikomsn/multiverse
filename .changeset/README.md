# Changesets

A file here is a changeset: it says that the terminal card (`apps/cli`, `grikomsn` on npm) changed, and how much. `bunx changeset` writes one. `bunx changeset version` reads them all, sets the card's new version, writes its `CHANGELOG.md` and deletes them.

The steps of a release are in [docs/apps/cli.md](../docs/apps/cli.md#release).
