## v9: griko.id (multiverse `9f45c656`)

### 1. TL;DR

A dark, minimal Tailwind portfolio, built on Next.js pages router plus a DatoCMS GraphQL backend through a `graphql.griko.id` proxy. The DatoCMS project is gone (asset URLs return 404) and so is the proxy. It also depends on a private GitHub Packages font (`@grikomsn/private-fonts`, Berkeley Mono). That makes an original-toolchain build (C) infeasible without rewriting the data layer. Every rendered page is still in the Wayback Machine as `__NEXT_DATA__` JSON, so the content can be recovered exactly. **Recommendation: B.** Port the look to Astro 7 + Tailwind 4 and freeze the Wayback-recovered data as JSON. Swap Berkeley Mono for a free mono unless the license allows self-hosting.

### 2. Overview

- **Era:** the zip has no git metadata. File mtimes and the lockfile (`next 13.0.2`, released 2022-11-01) put the final commit at **~2022-11-07**. The Wayback `griko.id` captures in this layout run from **2022-01-21** (`/playground/seat-selector`) to **2022-09-30**. The site was replaced when the owner moved to nibras.co ("New Domain, New Me", 2022-11-11).
- **Stack:** pnpm workspace + Turborepo 1 (`v9/package.json`, `v9/turbo.json`). The single app `v9/website` uses Next `^13` (lock 13.0.2, pages router), React 18, Tailwind `^3` (lock 3.2.2) with forms/typography/line-clamp/aspect-ratio, `next-mdx-remote` 4 with rehype-pretty-code/shiki, GraphQL Codegen generating `@tanstack/react-query` v4 hooks, zustand, Radix Tooltip, Headless UI, react-hot-toast, tinykeys, iconoir-react, next-seo, next-sitemap and feed. Node is `lts/*` (`v9/.nvmrc`). The private registry `@grikomsn:registry=https://npm.pkg.github.com` is set in `v9/.npmrc`.
- **Deploy target:** Vercel (`v9/website/vercel.json` runs `pnpm prebuild && pnpm build`, and the footer says "Hosted on Vercel"). It used ISR-style `getStaticProps`/`getStaticPaths` with `fallback: "blocking"`, so it was not a pure static export.
- **Domain:** `griko.id` (`v9/website/config/metadata.json`, email `hello@griko.id`). griko.id is now an unrelated WordPress site.
- **Ever live:** yes, at griko.id through 2022 (Wayback captures above).

#### Playground: `/playground/seat-selector` in detail

- **What it is:** a static demo built because "A friend asked how to make a seat selector UI, soooo yeah" (its page description). It is a cinema or bus-style seat map. **It is unrelated to the game "Is This Seat Taken?"** That game is a puzzle about placing passengers by their preferences. This page has no puzzle, no characters and no state.
- **How it's built** (`v9/website/pages/playground/seat-selector.tsx`, 81 lines):
  - A hardcoded 4×8 matrix `EXAMPLE_SEATS` holds per-seat state: `-1` means no seat or aisle (rendered with `hidden`), `0` means available, `1` means taken and `2` means reserved/highlighted.
  - It renders a CSS grid with `gridTemplateColumns: repeat(COLUMNS, minmax(0,1fr))`.
  - Each seat is a 32px `<button>` labelled with its `row`+`col` index string. Available seats are bordered `neutral-500` with a hover fill. State 1 is filled `neutral-500`. State 2 is filled `primary-700` (Tailwind `yellow-700`). Any state above 0 is `disabled`.
  - **There is no selection logic.** Clicking an available seat does nothing, nothing is stored and there is no `useSeo` call (so it falls back to default meta).
- **Reusability:** low as code (~30 lines of markup), but the data model (2D matrix of seat states, aisle gaps as `-1`) is a fine seed. A new "seat" interaction in the Is-This-Seat-Taken-inspired design would need real state (selected, occupant, preference), so write it fresh as an Astro island or vanilla script. Porting this verbatim into the v9 archive is trivial (pure markup plus Tailwind classes).

`/playground/time` uses the `useTimeStore` zustand store, ticked by `requestAnimationFrame` (`store/time/*`), and formats with `date-fns-tz` `formatInTimeZone` (`"PPPP"` and `"HH:mm:ss zzz"`). A ~20-line vanilla `Intl.DateTimeFormat` script can replace it.

### 7. Visual identity

- **Dark only** (`:root { color-scheme: dark }`). Background `neutral-900`, text `neutral-300`, headings `neutral-200`, muted text `neutral-400`. Primary is Tailwind `yellow` (links `primary-500`, selection `primary-500/50`). Font sizes run one step larger than Tailwind's defaults (`base` = 1.125rem; see `tailwind.config.js`).
- **Typefaces:** Plus Jakarta Sans (with `ss01`–`ss03` explicitly off) and Berkeley Mono.
- **Layout:** a single centered `max-w-4xl` column. Page headers sit 10–20vh down, using the prose `h1` plus `.lead` paragraph.
- **Signature effect:** a floating **bottom nav "dock"**. It is a fixed, centered, rounded-xl `neutral-800/80` bar with backdrop blur, a shadow, the 400px avatar icon on the left and links on the right, with a fade gradient from the bottom (`ui/navigation/index.tsx`). Other details:
  - Pages animate in with `slide-down-fade`, and the dock with `slide-up-fade` (`tailwind.preset.js`, Radix demo keyframes).
  - Project cards show the screenshot offset `translate-x-6 translate-y-6 scale-110` inside a rounded tile, nudging up on hover (`ui/project/image.tsx`).
  - Talk and post rows get a `neutral-800` rounded hover with a full-card link overlay.
  - Code blocks use shiki `github-dark` with highlighted lines tinted `primary-500/20`.
  - Headings get a hover link icon in the left gutter.

## 2023a: Chakra + Lenis (nibras.co, Apr to Aug 2023)

### 1. TL;DR

A small, fully self-contained Next 13.4 app-router site (5 routes) with Chakra UI, a mouse-following blurred-gradient background, Lenis smooth scroll and a hand-drawn signature SVG. **All content is hardcoded** (`data/showcase.ts` and inline markdown), so there's no CMS dependency. **Recommendation: B.** Port to Astro + Tailwind 4 with the data copied verbatim; it's an S–M job. C is viable as a fallback (all deps are public). However, the original renders nothing until hydration (`useIsMounted() ? children : null`), so a static export would be an empty HTML shell.

### 2. Overview

- **Era:** first commit `2b29698` "init" on **2023-04-15** and last commit `93a6838` on **2023-08-16** (38 commits). Uncommitted dep bumps sit in `package.json` and `pnpm-lock.yaml` (Next 13.4.16 → 13.4.19 and so on). Do not build from the working tree. Use `HEAD`.
- **Stack:** Next `^13.4.19` (app router; every page is `"use client"`), React 18, Chakra UI 2.8 + Emotion + `@chakra-ui/next-js`, framer-motion 10 (via Chakra), `@studio-freight/lenis` 1.0.19, `react-markdown` 8 + remark-gfm, react-icons 4, `@vercel/analytics` 1, zustand 4, TypeScript 5.1, turbo 1.10 (wrapper scripts `build`, `dev`, `start`), pnpm, `.nvmrc` `lts/*`.
  - Installed but **unused**: `@tanstack/react-query` (no `QueryClient` anywhere), `fast-fuzzy`, `zod`, `@wry/equality`, `date-fns`.
  - `next-axiom` was added on 2023-04-17 and removed on 2023-05-10 (`513959a`).
  - `@grikomsn/style-guide` is on public npm.
- **Deploy target:** Vercel (`vercel.d.ts`, `@vercel/analytics`, `VERCEL_URL` fallback in `config/constants.ts`).
